1. 설치와 접속

서버 PC에서 처음 실행하기

  1. FREE ZIP을 일반 폴더에 완전히 압축 해제합니다.
  2. ONE_CLICK_START.bat을 더블클릭합니다.
  3. 관리자 권한 요청이 나오면 예를 누릅니다.
  4. Python이 없으면 자동 설치되고, 전용 가상환경과 필수 패키지가 준비됩니다.
  5. 완료 화면의 주소를 확인합니다. 서버 PC는 http://localhost:5001을 사용합니다.
첫 실행은 인터넷, Windows winget, 관리자 권한이 필요하며 몇 분 걸릴 수 있습니다. 완전 오프라인 설치 파일은 아닙니다.
예시 데이터 안내. 처음 실행하면 네이버·카카오 등 누구나 아는 이름으로 된 예시 거래처·품목·입출고 데이터가 미리 들어 있어 바로 화면을 둘러볼 수 있습니다. 실제 데이터를 입력하기 전에 설정 → 회사·DB → 완전 초기화로 지우고 시작하세요.

다른 사내 PC에서 접속하기

같은 공유기나 사내망의 다른 PC에서 실행 창에 표시된 http://서버PC주소:5001을 브라우저 주소창에 입력합니다. 서버 PC는 켜져 있어야 합니다.

다시 실행하거나 중지하기

  • 다시 시작은 ONE_CLICK_START.bat 또는 SERVER_RESTART.bat을 사용합니다.
  • 중지는 SERVER_STOP.bat을 사용합니다.
  • 자동 실행은 start_hidden.vbs 바로가기를 Windows 시작프로그램에 등록합니다.

3. 홈·캘린더·메모

🏠 홈

로그인 후 가장 먼저 보이는 요약 화면입니다. 홈 달력에서 날짜를 확인하고, 일정과 매입·매출 요약, 최근 공지 영역, 개인 메모를 한 번에 확인합니다.

📅 캘린더

  • 일간은 하루의 시간대별 일정과 할 일을 자세히 봅니다.
  • 일간 화면의 미니 달력은 일정이 없는 날짜에도 0건을 표시하고, 일정이 있으면 1건·2건처럼 실제 건수를 표시합니다.
  • 주간은 선택한 7일 일정과 주차 계획을 함께 관리합니다.
  • 월간은 한 달 전체 일정을 빠르게 확인합니다.
  • 날짜나 빈 시간대를 눌러 제목, 기간, 메모와 색상을 입력합니다.
  • 한국 공휴일과 직접 등록한 일정이 함께 표시됩니다.

✅ 투두에서 일정 자동 등록

  1. 일간 화면의 투두 입력칸에 17일을 씁니다.
  2. Space를 누르면 현재 미니 달력에서 선택한 달을 붙여 7월 17일 날짜 칩으로 바뀝니다.
  3. 8시에를 쓰고 다시 Space를 누르면 8시 시간 칩으로 바뀝니다.
  4. 약속을 입력하고 Enter 또는 추가를 누릅니다.
  5. 선택한 달의 17일에 투두가 저장되고 같은 날짜의 08:00~09:00 일정이 함께 만들어집니다.
입력 예시등록 결과
17일 8시에 약속선택한 달의 17일 투두와 08:00~09:00 일정.
07/17 점심식사7월 17일 투두와 시간 없는 일정.
07-17 09시~10시 거래처 전화7월 17일 09:00~10:00 투두와 일정.
아홉시까지 보고서저장한 현재 시각부터 가장 가까운 오전 또는 오후 9시까지 일정.
12시까지 발주 확인저장한 현재 시각부터 가장 가까운 12시까지 일정.
17일처럼 월을 생략하면 미니 달력에 현재 표시된 선택 월을 사용합니다. 날짜를 쓰지 않으면 현재 열어 둔 일간 날짜에 저장되고, ~시까지의 시작 시각은 입력을 저장한 실제 시각입니다.

📝 메모

개인 업무를 짧게 기록하는 공간입니다. 태그를 선택하거나 새 태그를 만들고, 메모를 드래그해 순서를 바꿀 수 있습니다. 끝난 메모는 완료 처리한 뒤 완료목록에서 검색하거나 날짜로 찾습니다.

4. 거래처와 품목 등록

🏬 거래처 등록

  1. 관리 → 거래처 등록을 엽니다.
  2. 직접 등록을 누르고 거래처명, 사업자번호, 대표자, 연락처 등을 입력합니다.
  3. 필요하면 거래처 사진이나 사업자등록증 이미지를 첨부합니다.
  4. 저장 후 검색창으로 거래처를 찾아 수정하거나 삭제합니다.

📦 품목 등록

  1. 관리 → 품목 등록에서 직접 등록을 누릅니다.
  2. 중복되지 않는 품목코드, 품목명, 규격, 단위, 위치, 매입가와 판매가를 입력합니다.
  3. 품목이 많으면 양식 다운로드 후 XLSX 또는 CSV를 작성해 양식 업로드를 사용합니다.
  4. 설정 → 테이블 관리에서 헤더 이름과 표시 여부를 정하고, 열 순서는 품목 목록 표의 실제 헤더를 좌우로 드래그해 조절합니다.
입출고를 시작하기 전에 품목코드를 먼저 확정하세요. 같은 품목에 여러 코드를 사용하면 재고가 나뉘어 계산됩니다.

5. 재고 현황과 입출고

🔄 입고 처리

  1. 입출고 관리에서 입고를 누르거나 F9를 누릅니다.
  2. 품목코드를 입력하고 Enter를 눌러 목록에 추가합니다.
  3. 수량과 매입 단가를 확인하고 비고를 입력합니다.
  4. 전체 입고 처리를 눌러 저장합니다.

🔄 출고 처리

  1. 입출고 관리에서 출고를 누르거나 F10을 누릅니다.
  2. 품목코드를 입력하고 수량·판매 단가를 확인합니다.
  3. 필요하면 채널, 주문번호, 송장번호와 비고를 입력합니다.
  4. 전체 출고 처리를 누르고 재고 현황에서 수량을 확인합니다.

📊 재고 현황

표 보기와 카드 보기를 선택할 수 있습니다. 위치, 현재고 상태, 품목명, 단위로 필터링하고 위치순·현재고순·품목명순으로 정렬합니다. 엑셀 다운로드로 현재 재고를 별도 보관할 수 있습니다.

FREE는 PC 고정 화면 방식입니다. 모바일 카메라 바코드 스캔과 모바일 전용 화면은 Pro 기능이며, FREE에서는 품목코드를 직접 입력하는 방식을 권장합니다.

6. 설정과 백업

설정 메뉴하는 일권한·저장 범위
회사·DB회사명, 홈 매입·매출 기본기간(일간·주간·월간)과 거래 유형 색상을 저장합니다. 관리자는 FREE용 6개 DB의 백업·복원과 업무 데이터 완전 초기화도 관리합니다.회사·DB 작업은 관리자 전용입니다. 홈 기본기간과 거래 유형 색상은 일반 사용자도 변경할 수 있지만 서버 공용이라 같은 서버의 모든 사용자 화면에 적용됩니다.
내 계정아이디, 비밀번호, 이름, 이메일, 찾기 질문을 변경합니다. 관리자는 회원을 검색하고 일반·관리자 권한을 정합니다.내 정보는 현재 사용자 계정에 서버 저장되어 다른 PC·브라우저에서도 이어집니다. 회원 관리는 관리자 전용입니다.
단축키기능 키와 사이드바 단축키 표시 여부를 바꾸고 기본값으로 되돌립니다.사용자별 서버 저장이라 같은 계정으로 로그인하면 다른 PC·브라우저에도 적용됩니다.
빠른실행상단에 표시할 입고·출고·메모·거래처 등 자주 쓰는 버튼을 선택합니다.사용자별 서버 저장이며 다른 사용자의 버튼 구성에는 영향을 주지 않습니다.
테이블 관리거래처·품목·재고현황·입출고 표의 헤더 이름과 표시 여부를 관리합니다. 열 순서는 각 목록 표의 실제 헤더를 좌우로 드래그해 바꿉니다.현재 브라우저 프로필에만 로컬 저장되며 사용자 계정이나 서버에는 동기화되지 않습니다.
Pro 전환발급받은 Pro 코드 전체를 붙여넣어 현재 데이터를 유지한 채 Pro 기능을 엽니다.관리자만 실행할 수 있고 서버 전체에 적용됩니다.

설정 탭을 사용하는 순서

  1. 좌측 설정 메뉴에서 바꿀 항목을 선택합니다.
  2. 위 표에서 관리자 전용인지, 서버 공용인지, 사용자별인지, 현재 브라우저 전용인지 먼저 확인합니다.
  3. 현재 값을 확인하고 필요한 항목만 변경합니다.
  4. 해당 화면의 저장 또는 적용 버튼을 누른 뒤 성공 안내를 확인합니다.
  5. 테이블 열 순서를 바꿀 때는 설정을 닫고 해당 목록 표의 실제 헤더를 원하는 위치로 드래그합니다.
Pro 전용. FREE에서는 출력 디자인·멀티검색 설정과 관리자의 출퇴근·전체 히스토리가 보이지 않습니다. 관리자 캘린더에 직원 출퇴근 시각을 표시하는 옵션도 Pro 전용이며, Pro 전환이 완료되면 해당 설정 메뉴가 열립니다.

안전한 DB 백업 방법

  1. 관리자 계정으로 설정 → 회사·DB를 엽니다.
  2. FREE에 표시되는 사용자/권한/회사설정, 거래처, 품목(품목코드), 매입/매출 전표, 일정/공휴일, 개인 메모의 6개 DB 중 필요한 행의 받기를 누릅니다.
  3. 다운로드한 DB 파일을 날짜와 DB 종류가 구분되도록 외장 저장소나 클라우드에 보관합니다.
  4. 복원할 때는 반드시 같은 종류의 DB 행에서 복원을 누르고 해당 파일을 선택합니다.
업무 데이터 완전 초기화는 거래처·품목·입출고·매입매출·전표·일정·프로젝트·메모·공지·출퇴근·히스토리와 업무 첨부파일을 삭제합니다. 회원 계정, 회사·사업자 정보, 출력 설정, 사용자별 환경설정과 회사 로고·워터마크·도장 자산은 유지됩니다. 실행 전 서버 내부에 자동 백업 폴더가 만들어지지만 외부 수동 백업을 대신하지 않으므로, 초기화 전에 위 6개 DB를 직접 내려받아 별도 장치에 보관하세요.

7. Pro 버전으로 전환하기

  1. 판매자에게 받은 PRO CODE 전체를 준비합니다.
  2. 관리자 계정으로 로그인합니다.
  3. 설정 → Pro 전환을 엽니다.
  4. 코드 전체를 붙여넣고 Pro로 전환을 누릅니다.
  5. 완료 안내 후 화면이 다시 열리면 프로젝트·전표 등 Pro 메뉴가 표시됩니다.
전환해도 기존 거래처·품목·입출고·메모 데이터는 유지됩니다. 재설치 후에도 같은 코드를 다시 입력할 수 있습니다.

9. 자주 발생하는 문제

ONE_CLICK_START.bat이 설치 중 멈춥니다.
인터넷 연결과 winget 사용 가능 여부를 확인하고 관리자 권한으로 다시 실행하세요. 폴더의 install-start.log 마지막 부분에서 실제 오류를 확인할 수 있습니다.
다른 PC에서 접속되지 않습니다.
서버 PC가 켜져 있는지, 두 PC가 같은 네트워크인지, 실행 화면의 IP 주소와 5001 포트를 정확히 입력했는지 확인합니다. Windows 방화벽 승인도 필요합니다.
admin 비밀번호를 잊었습니다.
미리 저장한 이메일과 찾기 질문 답변으로 재설정합니다. 아무 정보도 등록하지 않았다면 정상적인 화면 절차로 복구할 수 없으므로 최초 로그인 직후 반드시 설정하세요.
재고 수량이 예상과 다릅니다.
입출고 관리에서 해당 품목코드의 입고·출고·반품 내역을 확인합니다. 같은 품목이 다른 품목코드로 중복 등록되지 않았는지도 확인하세요.
백업 파일을 복원했는데 일부 내용만 바뀝니다.
데이터가 도메인별 DB로 나뉘어 있으므로 선택한 DB 종류만 복원됩니다. 필요한 다른 DB도 각각 복원해야 합니다.
