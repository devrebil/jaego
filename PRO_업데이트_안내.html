📦 PRO 재고관리 업데이트 안내

기존 데이터는 그대로 유지됩니다.
거래처, 품목, 입출고, 전표, 일정, 계정과 비밀번호는 모두 그대로이고, 예시(연습용) 데이터는 다시 생기지 않습니다. 업데이트로 바뀌는 것은 프로그램 기능뿐입니다.

시작하기 전에 꼭 확인해 주세요

  • 업데이트는 지금 쓰시던 폴더 위에 덮어쓰는 방식입니다. 기존 폴더를 지우거나 새 빈 폴더에 설치하지 마세요.
  • 업데이트 파일에는 고객님의 데이터가 들어 있지 않습니다. 데이터는 설치 폴더 안의 db 폴더와 uploads 폴더에 있으며, 덮어써도 그대로 남습니다.
  • 만약을 위해 업데이트 전에 백업을 한 번 받아 두시길 권합니다. (아래 1단계)

방법 A. ZIP 파일로 설치해서 쓰시는 경우 (ONE_CLICK_START.bat)

  1. 백업 받기
    프로그램에 관리자로 로그인 → 설정 → 회사·DB 에서 백업 파일을 받기 합니다. 받은 파일은 USB나 다른 폴더에 보관하세요. 설치 폴더 전체를 통째로 복사해 두면 더 안전합니다.
  2. 프로그램 종료
    다른 PC에서 쓰고 있는 분들은 작업을 마치게 한 뒤, 서버 PC의 설치 폴더에서 SERVER_STOP.bat 을 더블클릭합니다.
  3. 새 버전 덮어쓰기
    새로 받은 PRO.zip 을 임시 폴더에 압축 해제합니다. 압축 해제된 파일 전체를 기존 설치 폴더에 붙여넣고, "대상 폴더의 파일 바꾸기"를 선택합니다. (db, uploads 폴더는 새 파일에 없으니 그대로 남습니다.)
  4. 다시 실행
    기존 설치 폴더의 ONE_CLICK_START.bat 을 더블클릭합니다. 필요한 구성요소를 확인·업데이트한 뒤 서버가 실행됩니다. 처음에는 몇 분 걸릴 수 있습니다.
  5. 확인하기
    브라우저에서 접속한 뒤 Ctrl + F5 로 새로고침하고, 기존 로그인 정보로 들어가 거래처·품목·입출고가 그대로 있는지 확인합니다.

방법 B. 설치 프로그램(Setup.exe)으로 설치해서 쓰시는 경우

  1. 백업 받기 — 위 방법 A의 1번과 같습니다.
  2. 프로그램 종료
    화면 오른쪽 아래 트레이 아이콘(파란 아이콘)을 우클릭 → 서버 종료. 종료할 때 전체 DB가 자동으로 한 번 더 백업됩니다.
  3. 새 설치 파일 실행
    새로 받은 PRO재고관리_Setup.exe 를 실행하고, 설치 위치를 바꾸지 말고 기본값 그대로 설치합니다. 기존 데이터는 그대로 이어집니다.
  4. 확인하기 — 설치가 끝나면 자동 실행됩니다. 접속해서 기존 데이터가 그대로 있는지 확인하세요. "Windows 시작 시 자동 실행" 옵션은 설치 중 선택 화면이나 트레이 아이콘 메뉴에서 다시 바꿀 수 있습니다.

업데이트 후 이런 경우에는

증상원인과 해결
연습용 예시 데이터(네이버, 카카오 등)가 보이고 제 데이터가 없어요 기존 폴더가 아닌 새 폴더에 설치하셨을 가능성이 큽니다. 데이터는 예전 폴더의 db, uploads 폴더에 그대로 있습니다. 프로그램을 종료한 뒤 그 두 폴더를 새 폴더로 복사하거나, 예전 폴더에서 다시 실행하세요.
화면이 예전 모습 그대로예요 브라우저가 예전 화면을 기억하고 있습니다. Ctrl + F5 로 새로고침하세요.
문제가 생겨서 이전 상태로 돌리고 싶어요 업데이트 전에 받아 둔 백업으로 설정 → 회사·DB → 복원 하거나, 통째로 복사해 둔 예전 폴더를 사용하세요.
다른 PC에서 접속이 안 돼요 서버 PC에서 프로그램이 실행 중인지 확인하세요. 서버 PC가 꺼져 있거나 절전 상태이면 접속할 수 없습니다.

처음 설치하시는 분께

처음 설치하면 연습용 예시 데이터가 들어 있어 기능을 둘러볼 수 있습니다. 실제로 사용하기 전에 설정 → 회사·DB → 완전 초기화 를 눌러 예시 데이터를 모두 지우고 시작하세요. (회원 계정과 회사·출력 설정은 유지되고, 초기화 직전에 자동 백업됩니다. 지운 뒤에는 화면에서 바로 복구할 수 없습니다.)
이미 업무 데이터를 입력하신 뒤에는 완전 초기화를 누르지 마세요.

새로 추가·개선된 기능

  • 입출고 내역 수정·삭제 기능 (잘못 입력했을 때 바로 고칠 수 있습니다)
  • 입고·출고 화면에 거래처 입력, 품목 등록 단가 자동 적용, 미등록 품목 수동 입력
  • 화면 표기를 매입단가 / 판매단가로 변경
  • 품목·입출고·재고 표에서 제목을 눌러 정렬, 페이지 나눔
  • 입출고 내역이 많아도 더보기로 계속 불러오기 (불러오는 중에는 진행 상황이 표시됩니다)
  • 거래명세표에서 오래된 거래까지 모두 조회
  • 자동 백업(10분마다·종료할 때), QR로 휴대폰 접속, 사용설명서(F7)

문의사항이 있으시면 판매처로 연락해 주세요.
