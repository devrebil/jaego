# 📦 재고 관리 Pro

매입·매출·재고를 관리하는 사내용 웹앱입니다. 도메인별로 SQLite DB 파일을 분리해
**위급 시 특정 DB만 따로 백업/복원**할 수 있고, **모든 쓰기 액션이 감사 로그(히스토리)** 로 남습니다.

## Windows 원클릭 설치 / 실행 (권장)

서버로 사용할 A PC에서 **`ONE_CLICK_START.bat`을 더블클릭**합니다.

- 관리자 권한 확인 창에서 **예**를 누르면 Python 확인, 가상환경 생성, 필수 패키지 설치,
  Windows 방화벽 허용, 서버 실행까지 자동 처리합니다.
- 첫 실행 뒤에는 같은 파일을 다시 더블클릭하면 필요한 업데이트를 확인하고 바로 실행합니다.
- A PC에서는 `http://localhost:5000`, 같은 공유기/사내망의 B·C·D PC에서는 실행 창에
  표시되는 `http://<A PC IP>:5000` 주소로 접속합니다.
- A PC가 꺼지거나 절전 상태이면 다른 PC에서는 접속할 수 없습니다.
- 최초 로그인 계정은 **admin / admin**이며, 첫 로그인 직후 반드시 비밀번호를 변경하세요.

### 새 Windows PC에서 필요한 조건

- ZIP을 먼저 일반 폴더에 완전히 압축 해제한 뒤 `ONE_CLICK_START.bat` 하나만 실행합니다.
- Python이 없으면 스크립트가 `winget`으로 Python 3.12를 설치합니다.
- 첫 실행에는 인터넷 연결, Windows의 `winget`, 관리자 권한 승인이 필요합니다.
- Python과 필수 패키지 설치 때문에 첫 실행은 즉시 끝나지 않으며 몇 분 걸릴 수 있습니다.
- 인터넷이나 `winget`이 없는 PC에서는 Python을 별도로 설치해야 합니다.

## 수동 설치 / 실행
```bash
pip install -r requirements.txt
python app.py
```
- Windows에서 서버 창 없이 실행하고 웹페이지를 자동으로 열려면 `start_hidden.vbs`를 더블클릭합니다.
- 배포 PC 시작 시 자동 실행하려면 `start_hidden.vbs`의 바로가기를 Windows 시작프로그램 폴더에 넣습니다.
- 접속: `http://localhost:5000`
- 사내 다른 PC에서 접속: `http://<서버 PC의 IP>:5000`
- 최초 로그인 계정: **admin / admin** (설정 > 내 계정에서 변경 가능)

## 주요 기능
- **로그인 / 회원가입** : 이름·비밀번호·생일·부서로 가입
- **홈 대시보드** : 달력+오늘일정 / 공지(권한자만 작성)+매입매출현황(일·주·월) / 프로젝트·메모
- **캘린더(월간)** : 네모박스 달력, 날짜 아래에 일정 표시, 날짜 드래그로 여러 날 일정 추가, 진행중/완료 탭, 관리자 출퇴근 표시 토글
- **프로젝트** : 히스토리 카드 누적 + Slack식 댓글/대댓글, 시작/완료가 달력에 표시
- **메모** : 개인 메모, 태그+Enter 작성, 드래그 정렬, 완료목록 검색·날짜필터
- **관리**
  - 거래처 등록(사진·사업자등록증 첨부)
  - 품목 등록(엑셀/CSV 일괄 업로드: SKU|품목명|규격|단위|매입가|판매가, 컬럼 ON/OFF)
  - 매입·매출 등록(구분 추가 가능, 컬럼 ON/OFF)
  - 재고 현황 / 월간·년간 입출 현황(표 + 그래프)
- **입출고 관리** : 매입=입고·매출=출고로 재고 반영
- **설정** : 회사명·권한 관리, DB 백업/복원, 전체 히스토리 조회

## DB 구조 (도메인별 파일 분리)
`db/` 폴더 안에 도메인마다 별도 `.db` 파일:
`users / contacts / items / transactions / inventory / calendar / projects / memo / attendance / notice / audit`

- 백업: 설정 화면에서 DB별 [받기] → `.db` 파일 다운로드
- 복원: DB별 [복원] → 해당 파일만 교체 (기존 파일은 `.bak`로 보관)

## 폴더 구조
```
app.py              # Flask 라우팅 / API
db.py               # 도메인별 DB 연결 + 감사로그
templates/index.html# 단일 페이지 프론트엔드
db/                 # SQLite 파일들 (최초 실행 시 생성)
uploads/            # 첨부파일 (사진/사업자등록증)
```
