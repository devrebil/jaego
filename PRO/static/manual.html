처음 사용자

1. 처음 실행하기

압축을 푼 다음 ONE_CLICK_START.bat를 한 번 실행하면 됩니다. (설치형 배포판은 Setup.exe를 실행합니다.)

  1. PRO 압축 파일을 별도 폴더에 완전히 풉니다. 압축 파일 안에서 바로 실행하지 마세요.
  2. ONE_CLICK_START.bat를 더블클릭합니다. 첫 실행은 필요한 구성요소를 준비하므로 시간이 조금 걸릴 수 있습니다.
  3. 표시된 주소를 웹 브라우저에서 엽니다. 기본 PC 접속 포트는 5000입니다.
  4. 초기 계정 admin / admin으로 로그인한 뒤 설정에서 비밀번호를 즉시 변경합니다.
파이썬이 없는 PC도 실행할 수 있도록 시작 파일이 준비되어 있습니다. 다만 첫 실행 때 인터넷 연결, Windows의 구성요소 설치 허용 또는 관리자 권한이 필요할 수 있습니다.
여러 PC에서 사용할 때는 프로그램을 실행한 서버 PC를 계속 켜 두어야 합니다. 다른 PC는 서버 화면에 표시된 내부 네트워크 주소로 접속합니다.
예시 데이터로 시작합니다. 처음 실행하면 네이버·카카오 같은 예시 거래처와 품목·입출고·프로젝트 데이터가 미리 들어 있어 바로 화면을 둘러볼 수 있습니다. 실제 업무 데이터를 입력하기 전에 설정 → 회사·DB → 완전 초기화로 예시 데이터를 지우고 시작하세요.
이 설명서는 언제든 다시 열 수 있습니다. 프로그램 화면 어디에서나 키보드의 F7을 누르면 새 탭으로 이 설명서가 열립니다. 급할 때 바로바로 확인하세요.

새 투두 입력

4. 날짜와 시간을 쓰면 일정도 함께 만들어집니다

  1. 캘린더의 일간 화면에서 투두 입력칸을 누릅니다.
  2. 17일을 쓰고 스페이스를 누르면 현재 열어 둔 달을 기준으로 7월 17일 날짜 칩이 생깁니다.
  3. 8시에를 쓰고 스페이스를 누르면 조사 ‘에’가 정리되어 8시 시간 칩이 생깁니다.
  4. 뒤에 할 일을 쓰고 Enter 또는 추가를 누릅니다.
투두와 일정이 한 번에 등록됩니다. 7월 일간 화면에서 17일 8시에 약속을 입력하면 투두와 08:00~09:00 일정이 모두 7월 17일에 저장됩니다.
일간 화면 왼쪽 달력은 날짜마다 일정 수를 0건, 1건…으로 표시합니다. 자동 일정이 등록되면 해당 날짜의 건수도 함께 갱신됩니다.
업무 예시

5. 일상 업무는 이렇게 처리하세요

상품을 새로 받았을 때

관리 → 입출고 관리에서 입고 버튼을 누르고 거래처와 품목·수량을 담아 저장합니다. 등록된 품목이면 단가가 자동으로 채워집니다.

상품을 내보냈을 때

관리 → 입출고 관리에서 출고 수량을 저장합니다. 판매 기록이 필요하면 판매입력도 함께 작성합니다.

고객에게 견적을 보낼 때

전표 → 견적서 입력에서 거래처와 품목을 선택하고 저장한 뒤 인쇄 또는 PDF로 전달합니다.

팀 업무를 진행할 때

프로젝트에서 담당자와 상태를 지정하고 댓글과 @멘션으로 진행 내용을 남깁니다.

입력 후 확인 습관이 중요합니다. 입출고는 재고 현황에서, 판매와 견적은 각각의 조회 메뉴에서 저장 결과를 바로 확인하세요.
창고에서는 휴대폰으로. 화면 상단의 모바일 접속 주소를 눌러 QR코드를 스캔하면 휴대폰으로 바로 접속되고, 카메라로 바코드를 찍어 입고·출고를 처리할 수 있습니다. 자세한 방법은 자세한 설명의 "모바일에서 접속하기"를 확인하세요.

6. 안전하게 사용하는 기본 원칙

  • 초기 관리자 비밀번호를 반드시 변경합니다.
  • 전체 DB는 10분마다·프로그램 종료 시·(설치형의 경우) Windows 종료 시에도 자동으로 백업되지만, PC 고장에 대비해 설정의 자동 백업 표에서 정기적으로 별도 저장소에도 백업 파일을 받아 둡니다.
  • 백업 파일은 프로그램이 설치된 PC 외의 USB나 별도 저장소에도 보관합니다.
  • 서버 창을 강제로 닫거나 PC 전원을 갑자기 끄지 않습니다.
  • 복원과 전체 초기화는 기존 데이터를 바꾸므로 백업 후 관리자만 실행합니다.
설치·접속

1. 설치와 접속

서버 PC에서 실행하기

  1. 배포받은 PRO 압축 파일을 쓰기 가능한 폴더에 완전히 풉니다. (설치형 배포판은 Setup.exe를 실행하면 이 과정이 자동으로 끝나고 시스템 트레이에 아이콘이 생깁니다.)
  2. ONE_CLICK_START.bat를 실행합니다. 첫 실행이 끝날 때까지 창을 닫지 않습니다.
  3. 시작 창에 표시되는 접속 주소를 Chrome 또는 Edge에서 엽니다.
용도기본 포트설명
PC 웹 접속5000서버 PC와 같은 사내 네트워크의 PC에서 접속합니다.
모바일 HTTPS5443휴대폰 카메라 스캔 등 보안 연결이 필요한 기능에 사용합니다.

다른 PC와 휴대폰에서 접속하기

서버 PC와 같은 공유기 또는 사내망에 연결하고 시작 화면에 표시된 서버 IP 주소를 입력합니다. 접속이 안 되면 서버 프로그램 실행 여부, Windows 방화벽 허용 여부, 같은 네트워크인지 순서대로 확인합니다.

QR코드로 더 쉽게 접속하기. 화면 상단의 📱 모바일 접속 주소를 클릭하면 QR코드 모달이 뜹니다. 휴대폰 카메라로 이 QR코드를 찍으면 주소를 직접 입력하지 않아도 바로 접속됩니다. 처음 접속할 때 나오는 보안 경고 화면과 자세한 절차는 바로 다음 "2. 모바일에서 접속하기"에서 화면과 함께 안내합니다.
프로그램 폴더를 네트워크 드라이브에서 직접 공동 실행하지 마세요. 서버 PC 한 곳에서만 실행하고 다른 사용자는 웹 브라우저로 접속하는 방식이 안전합니다.
모바일

2. 모바일에서 접속하기

사무실 PC에서 QR코드를 찍는 순간부터, 창고에서 바코드로 입고를 처리하기까지 화면을 그대로 따라오시면 됩니다.

2-1. QR코드로 접속하기

  1. PC 화면 오른쪽 위의 📱 모바일 접속 주소를 클릭합니다.
  2. QR코드가 담긴 창이 뜹니다. 휴대폰 카메라 앱(또는 QR 스캔 기능)으로 화면의 QR코드를 비춥니다.
  3. 휴대폰 화면에 알림이 뜨면 눌러서 접속합니다. 자동으로 안 열리면 인식된 주소를 직접 눌러주세요.

2-2. 처음 한 번, 보안 경고가 뜹니다 — 당황하지 마세요

휴대폰 카메라로 바코드를 스캔하려면 보안 연결(HTTPS)이 필요한데, 이 연결은 사내 PC가 스스로 발급한 인증서를 사용합니다. 그래서 처음 접속하면 아래처럼 "연결이 비공개로 설정되어 있지 않습니다" 같은 경고가 한 번 뜹니다. 해킹이나 오류가 아니라 정상적인 화면이니 순서대로 진행하면 됩니다.

  1. 이런 경고 화면이 보이면 놀라지 말고 맨 아래로 스크롤합니다.
  2. 화면 아래쪽의 "고급"을 누릅니다.
  3. 펼쳐지는 설명 아래 "◯◯◯(안전하지 않음)으로 이동" 링크를 누릅니다.
  4. 정상적으로 로그인 화면이 나타납니다. 이 과정은 같은 휴대폰에서 한 번만 하면 되고, 다음부터는 경고 없이 바로 접속됩니다.
같은 사무실 PC, 같은 서버에 접속하는 것이니 안심하고 진행하셔도 됩니다.

2-3. 카메라로 바코드 찍어서 바로 입력하기

위 과정을 한 번 거쳐 HTTPS로 접속하면, 입고·출고 화면에 📷 카메라 버튼이 나타납니다. 이 버튼은 휴대폰에서 HTTPS로 접속했을 때만 보입니다.

  1. 휴대폰에서 입고 또는 출고 버튼을 눌러 빠른 입고·출고 창을 엽니다.
  2. 품목코드 입력칸 옆의 📷 카메라 버튼을 누릅니다.
  3. 화면에 뜨는 사각형 안에 바코드를 맞추면 자동으로 인식되어 스캔 내역에 바로 추가됩니다.
  4. 계속 다른 바코드를 비추면 연속으로 여러 품목을 스캔할 수 있습니다.
  5. 등록되지 않은 바코드를 스캔하면 알림이 뜨고, 그 자리에서 새 품목으로 등록하거나 이번만 수동으로 이름과 단가를 입력해 추가할 수 있습니다.
카메라가 열리지 않으면 브라우저 주소창 옆의 사이트 설정에서 카메라 권한을 허용했는지 확인하세요. HTTP(5000) 주소로 접속했다면 카메라 권한이 있어도 실시간 스캔 대신 사진 촬영 방식으로 동작합니다.
사용자 관리

3. 계정과 권한

관리자

사용자, 회사 정보, DB 백업·복원, 공지, 출퇴근 설정과 전체 히스토리 등 관리 기능을 사용할 수 있습니다.

일반 사용자

부여된 업무 메뉴에서 일정, 메모, 전표, 재고와 프로젝트 업무를 처리합니다. 일부 관리자 메뉴는 보이지 않습니다.

  1. 초기 관리자 계정 admin / admin으로 로그인합니다.
  2. 설정 → 내 계정에서 관리자 비밀번호를 변경합니다.
  3. 필요한 직원 계정을 만들고 권한을 확인합니다.
  4. 각 직원이 자신의 계정으로 로그인되는지 확인합니다.
퇴사자나 더 이상 사용하지 않는 계정은 즉시 비활성화하거나 정리하고, 공용 계정 사용은 피하세요.

로그인 후 보이는 시작 화면입니다. 오늘 일정과 최근 업무 등 자주 확인할 정보를 모아 보여 줍니다. 상단 빠른실행은 설정에서 사용자가 원하는 메뉴로 바꿀 수 있습니다.

📅 캘린더 — 하나씩 눌러보며 따라 해보세요

캘린더는 일간·주간·월간 3가지 보기가 있고, 화면 위쪽 탭(또는 F1·F2·F3)으로 언제든 바꿀 수 있습니다. 토요일은 파란색, 일요일과 대한민국 공휴일은 빨간색으로 자동 표시되고, 매입·매출·반품 건수와 프로젝트 시작·완료일도 날짜 위에 함께 나타납니다.

4-1. 일간 보기 — 오늘 하루를 시간대별로

  1. 사이드바에서 캘린더를 클릭하거나 F1을 누릅니다. (처음 열면 일간 보기가 기본입니다.)
  2. 왼쪽의 작은 달력에서 원하는 날짜를 클릭하면 가운데 시간표가 그 날짜로 바뀝니다. 날짜 입력칸에 직접 날짜를 입력해도 됩니다.
  3. 가운데 "시간별 일정" 표에서 일정을 넣고 싶은 시간대를 클릭하거나, 여러 시간을 드래그해서 선택합니다. 또는 오른쪽 위 + 일정 버튼을 눌러도 됩니다.
  4. 제목, 시작·종료 시간, 메모, 색상을 입력하고 저장합니다.
  5. 저장한 일정이 시간표 위에 색깔 블록으로 나타납니다. 블록을 클릭하면 내용을 수정하거나 삭제할 수 있습니다.
  6. 오른쪽 "오늘의 투두리스트" 칸에 17일 8시에 회의처럼 날짜와 시간을 넣어 입력하면, 투두와 시간표 일정이 동시에 만들어집니다. (자세한 규칙은 아래 "투두에서 일정 자동 등록" 참고)

4-2. 주간 보기 — 이번 주를 한눈에, 주차별 계획도 함께

  1. 캘린더 위쪽에서 주간 탭을 클릭하거나 F2를 누릅니다.
  2. 왼쪽 월 달력에서 원하는 주가 포함된 날짜를 클릭하면, 오른쪽 7일 보드가 해당 주로 바뀝니다. 오늘이 포함된 주는 처음 열었을 때 자동으로 선택되어 있습니다.
  3. 오른쪽 7일 보드의 각 요일 칸에는 그날의 매입·매출·반품 건수, 등록된 일정, 프로젝트 마감, 공휴일이 함께 표시됩니다. 칸을 클릭하면 그 날짜에 일정을 추가할 수 있습니다.
  4. 화면 오른쪽 위 시작 요일 드롭다운에서 한 주의 시작을 일요일 또는 월요일로 바꿀 수 있습니다. (계정별로 저장됩니다.)
  5. 맨 아래 "◯월 주차 계획" 카드에 1주차부터 5주차까지 각각 중요한 할 일을 적고 저장을 누르면, 주 단위의 큰 계획을 따로 남길 수 있습니다. 현재 선택된 주차 카드가 파란 테두리로 강조됩니다.

4-3. 월간 보기 — 한 달 전체 흐름 확인

  1. 캘린더 위쪽에서 월간 탭을 클릭하거나 F3을 누릅니다.
  2. 원하는 날짜를 클릭하면 그 날짜에 일정을 추가하는 창이 뜹니다. 여러 날짜를 드래그하면 기간이 있는 일정을 한 번에 추가할 수 있습니다.
  3. 달력의 각 날짜 칸에는 그날 등록된 매입·매출·반품 건수, 프로젝트 시작/완료, 공휴일 이름이 함께 표시됩니다. 일정이 4개를 넘으면 "+N건 더"로 표시되니 눌러서 전체를 확인하세요.
  4. 오른쪽 "일정 리스트"에서 진행중 / 완료 탭을 눌러 전체 일정을 목록으로 보고, 완료 버튼으로 처리 상태를 바꿀 수 있습니다.
  5. 화면 위쪽의 ◀ ▶ 화살표나 좌측 미니 달력으로 다른 달로 이동합니다.

투두에서 일정 자동 등록

  1. 일간 화면의 투두 입력칸에 17일을 쓰고 스페이스를 누르면 현재 선택한 달을 붙인 7월 17일 칩이 만들어집니다. 7월 15일, 07-15, 07/15 형식도 지원합니다.
  2. 8시에를 쓰고 스페이스를 누르면 8시 칩이 만들어집니다. 9시부터10시까지, 09시~10시, 09:00~10:00 범위도 지원합니다.
  3. 할 일 내용을 쓰고 Enter 또는 추가를 누릅니다. 날짜 칩의 날짜로 화면이 이동하고 투두와 일정이 함께 표시됩니다.
입력 예시등록 결과
17일 8시에 약속선택한 달의 17일에 투두와 08:00~09:00 일정. 칩 표시는 ‘7월 17일’과 ‘8시’.
07/17 점심식사7월 17일 투두와 시간 없는 일정.
07-17 09시~10시 거래처 전화7월 17일 09:00~10:00 투두와 일정.
아홉시까지 보고서저장한 현재 시각부터 가장 가까운 오전 또는 오후 9시까지 일정.
12시까지 발주 확인저장한 현재 시각부터 가장 가까운 12시까지 일정.

일간 화면의 작은 월 달력은 일정이 없어도 0건을 표시하고, 일정이 생기거나 삭제되면 날짜별 건수를 다시 계산합니다.

날짜를 생략하면 현재 열어 둔 일간 날짜에 저장됩니다. `~시까지`의 시작은 투두를 저장한 실제 시각이며, 종료 시각이 이미 지났다면 다음으로 돌아오는 해당 시각을 사용합니다.

공지사항

관리자가 전체 사용자에게 안내를 등록합니다. 제목과 내용을 명확하게 쓰고, 오래된 공지는 필요에 따라 정리합니다.

프로젝트

  1. 새 프로젝트를 등록하고 제목, 기간, 담당자와 상태를 지정합니다.
  2. 가운데 화면에 글을 작성하면 새 글이 맨 위에 올라오고 이전 글은 아래로 내려가는 피드 형태로 쌓입니다. 위에서 계속 스크롤해 과거 기록을 확인합니다.
  3. 오른쪽 히스토리 목록에서 원하는 글의 제목을 누르면 화면이 그 글 위치로 자동 스크롤되고 테두리로 강조됩니다.
  4. 댓글과 답글을 남기고, 특정 사용자의 확인이 필요하면 @멘션을 사용합니다.
  5. 완료된 프로젝트는 삭제보다 보관 기능을 우선 사용해 기록을 남깁니다.

메모

즉시 기록할 내용을 저장하는 개인 업무 공간입니다. 나중에 찾기 쉽도록 제목이나 첫 문장에 거래처명·품목명 같은 검색어를 넣는 것이 좋습니다.

판매·견적

5. 전표와 견적서

판매입력

  1. 전표 → 판매입력을 엽니다.
  2. 거래처와 판매일자를 선택하고 품목을 추가합니다.
  3. 수량, 단가, 금액과 비고를 확인한 뒤 저장합니다.
  4. 판매조회에서 방금 저장한 전표를 다시 열어 내용이 맞는지 확인합니다.

견적서 입력과 전달

  1. 전표 → 견적서 입력에서 거래처와 유효기간 등 기본 정보를 입력합니다.
  2. 견적 품목, 수량, 단가와 추가 조건을 입력하고 저장합니다.
  3. 견적서 조회에서 열어 인쇄하거나 브라우저의 PDF 저장 기능으로 파일을 만듭니다.
  4. 실제 판매로 확정되면 견적 내용을 판매 전표로 전환하고 최종 내용을 다시 확인합니다.
판매 전표와 재고 출고는 목적이 다릅니다. 판매 금액 기록과 실제 재고 감소가 모두 필요한 업무라면 판매 저장 결과와 입출고 기록을 각각 확인하세요.
회사 로고, 도장, 워터마크, 색상과 인쇄 항목은 설정 → 출력 디자인에서 조정합니다. 실제 고객에게 보내기 전에 미리보기나 테스트 PDF로 한 번 확인하세요.
기초 자료

6. 거래처와 품목 등록

거래처 등록

거래처명, 사업자번호, 담당자, 연락처와 필요한 거래 정보를 입력합니다. 이름이 비슷한 거래처가 있으면 기존 자료를 검색한 뒤 등록해 중복을 막습니다. 여기서 등록한 거래처명은 입출고 입력 시 자동완성으로 바로 골라 쓸 수 있습니다.

품목 등록

품목코드, 품목명, 규격, 단위, 기본 가격, 보관 위치 등 업무에 필요한 정보를 입력합니다. 품목코드는 재고와 전표를 연결하는 기준이므로 이미 사용 중인 코드를 임의로 바꾸지 않는 것이 좋습니다. 목록의 각 행에서 수정·삭제 버튼으로 언제든 정보를 고칠 수 있습니다.

등록 전 확인

같은 거래처나 품목이 이미 있는지 검색합니다. 코드와 이름의 사내 표기 규칙을 통일합니다.

수정 후 확인

연결된 판매·견적·재고 화면에 원하는 이름과 단위가 표시되는지 확인합니다.

재고 업무

7. 재고 현황과 입출고

빠른 입고·출고 등록

  1. 관리 → 입출고 관리에서 입고 또는 출고 버튼을 누르거나 F9·F10을 누릅니다.
  2. 맨 위의 거래처 칸에 거래처명을 입력합니다. 미리 등록된 거래처명을 입력하면 자동완성으로 뜨고, 이 창에서 담는 모든 품목에 공통으로 적용됩니다.
  3. 품목코드를 입력하거나 📷 카메라로 바코드를 스캔해 담습니다. 등록된 품목이면 매입단가/판매단가가 단가에 자동으로 채워집니다.
  4. 스캔 내역 표의 품목 · 수량 · 단가 열에서 필요하면 수량이나 단가를 직접 고칩니다. 각 줄 아래에 수량×단가로 계산된 소계가, 표 위쪽에는 전체 합계 금액이 자동으로 표시됩니다.
  5. 업무 종류에 따라 전체 입고/출고 처리를 눌러 한 번에 저장합니다.
아직 품목 등록을 안 한 물건도 입고할 수 있습니다. 품목코드를 입력했는데 "등록되지 않은 품목코드"라고 나오면, 품목명과 단가를 직접 입력하고 이번만 수동으로 추가를 누르세요. 정식 품목으로 남기고 싶다면 대신 + 신규 품목 등록을 눌러 등록해도 됩니다.

입출고 관리 — 저장된 내역 수정·삭제

잘못 입력했거나 수량·거래처가 바뀌었다면, 입출고 관리 표의 각 줄 오른쪽 수정 버튼으로 날짜·구분·거래처·수량·단가·비고를 다시 고칠 수 있습니다. 잘못 등록된 줄은 삭제 버튼으로 지울 수 있으며, 삭제 전 한 번 더 확인 메시지가 뜹니다.

판매입력에서 자동으로 등록된 매출 줄은 입출고 화면에서 바로 수정·삭제할 수 없고, 판매전표 쪽에서 수정해야 합니다. 안내 메시지가 뜨면 그쪽 화면을 이용하세요.

재고 현황

표 또는 카드 형태로 현재 수량을 확인합니다. 위치, 현재고, 품목과 단위 기준으로 검색·필터·정렬할 수 있습니다. 엑셀 양식 다운로드와 업로드를 사용할 때는 원본 양식의 열 이름과 구조를 바꾸지 마세요.

입출 현황과 보고서

기간과 조건을 지정해 입고·출고 내역을 조회합니다. 월간·연간 보고서와 엑셀 출력으로 집계 내용을 확인할 수 있습니다.

출고 수량이 현재고보다 큰 경우를 주의하세요. 저장 전에 품목코드와 수량을 다시 확인하고, 잘못 저장한 내역은 수정 버튼으로 바로 고치거나 삭제 후 다시 입력하세요.
편의 기능

8. 출퇴근, 빠른실행과 멀티 검색

출퇴근

상단의 출퇴근 버튼으로 본인의 근무 기록을 남깁니다. 관리자는 설정의 출퇴근 관리에서 전체 기록과 운영 기준을 확인합니다.

빠른실행

자주 쓰는 메뉴를 상단에 배치합니다. 설정의 빠른실행에서 사용자 업무에 맞게 구성합니다.

멀티 검색

F4로 통합 검색을 열어 여러 업무 자료를 빠르게 찾습니다. 검색 대상은 설정에서 조정할 수 있습니다.

알림과 멘션

프로젝트 댓글 등에서 나를 @멘션한 내용을 확인합니다. 확인한 알림은 해당 업무로 이동해 처리합니다.

설정 안내

9. 설정과 데이터 백업

설정 항목주요 용도
회사·DB회사·사업자 정보, 홈 매입매출 기본기간(일간·주간·월간), 관리자 캘린더의 출퇴근 표시와 거래 유형 색상을 저장합니다. 관리자는 도메인별 DB 백업·복원과 업무 데이터 완전 초기화도 실행할 수 있습니다.
출력 디자인관리자가 견적서·명세표 색상, 로고, 워터마크, 도장, 홈페이지·계좌번호와 하단 순서를 설정합니다. 권장 원본 크기는 로고 1200×600, 워터마크 1600×800, 도장 600×600이며 저장 전 미리보기를 확인합니다.
내 계정현재 사용자의 아이디, 비밀번호, 이름, 이메일과 찾기 질문을 변경합니다. 관리자는 회원을 검색하고 일반·관리자 권한을 정합니다.
단축키현재 사용자의 F키와 조합키 기능, 사이드바 단축키 표시 여부를 변경합니다. 같은 기능을 지정하면 기존 단축키와 자동으로 맞바뀝니다.
빠른실행현재 사용자의 상단에 표시할 입고·출고·검색·메모·프로젝트·거래처·출퇴근 버튼을 선택합니다.
멀티 검색현재 사용자가 F4를 열었을 때의 시작 탭, 일반검색 사이트, 업무 바로가기 이름과 URL을 설정합니다.
테이블 관리거래처·품목·재고현황·입출고·전표 입력·전표 조회의 헤더 이름과 열 표시 여부를 관리합니다. 전표 입력·조회는 헤더 이름만 바꿀 수 있고, 열 순서는 각 실제 표의 헤더를 드래그해 변경합니다.
출퇴근관리자에게만 표시됩니다. 전체 또는 사용자별 출근·퇴근 시각, 근무 시간과 기록 수를 조회합니다.
전체 히스토리관리자에게만 표시됩니다. 도메인, 사용자와 기간으로 생성·수정·삭제뿐 아니라 로그인·로그아웃·접속·창닫기 기록도 조회합니다.

설정 값이 저장되는 범위

범위해당 설정적용 방식
모든 사용자 공용회사·사업자 정보, 홈 기본기간, 거래 유형 색상, 출력 디자인서버에 저장되어 모든 사용자와 PC에 적용됩니다. 회사·사업자 정보와 출력 디자인 변경은 관리자만 할 수 있지만, 홈 기본기간과 거래 유형 색상은 일반 사용자도 바꿀 수 있으므로 변경 전에 내부 기준을 확인하세요.
사용자별 서버 저장내 계정, 단축키, 빠른실행, 멀티 검색로그인 사용자별로 저장되어 같은 계정이면 다른 PC에서도 동일하게 적용됩니다.
현재 브라우저 저장테이블 헤더 이름·숨김, 실제 표에서 드래그한 열 순서현재 브라우저의 로컬 저장소에 보관되므로 다른 PC·브라우저나 같은 PC의 다른 브라우저로 자동 복사되지 않습니다.

설정 탭을 사용하는 순서

  1. 좌측 설정 메뉴에서 바꿀 항목을 선택합니다.
  2. 현재 저장값, 저장 범위와 미리보기를 먼저 확인합니다.
  3. 필요한 항목만 변경하고 해당 화면의 저장 버튼을 누릅니다.
  4. 단축키·빠른실행·멀티 검색은 각 직원 계정에서, 테이블 설정은 실제 사용하는 각 브라우저에서 확인합니다.
  5. 출력 디자인은 고객에게 보내기 전 테스트 PDF로 로고, 도장, 워터마크와 페이지 나눔을 점검합니다.
회사·사업자 정보, 출력 디자인, 회원 권한, DB 백업·복원·초기화, 출퇴근과 전체 히스토리는 관리자 기능입니다. 일반 사용자가 해당 입력을 바꾸지 못하거나 메뉴를 볼 수 없는 것은 정상입니다.

🕒 자동 백업

설정 → 회사·DB의 "자동 백업" 표에서 전체 DB 백업 현황을 확인합니다. 별도 조작 없이도 10분마다, 그리고 프로그램을 종료할 때 전체 DB가 자동으로 백업되며, 최근 200개까지 보관되고 오래된 백업은 자동으로 정리됩니다. 설치형(Setup.exe) 배포판은 Windows를 종료하거나 로그오프할 때도 종료 직전에 한 번 더 안전하게 백업한 뒤 꺼집니다.

  1. 지금 바로 백업하려면 지금 전체 백업 버튼을 누릅니다.
  2. 표의 각 줄에서 받기를 누르면 그 시점의 전체 DB를 zip 파일로 내려받습니다.
  3. 특정 시점으로 되돌리려면 복원을 누릅니다. 확인 메시지가 뜨고, 복원 전 현재 상태도 자동으로 한 번 더 백업된 뒤 선택한 시점으로 전체 DB가 교체됩니다.
자동 백업은 프로그램이 설치된 PC 안에만 저장됩니다. PC 고장이나 도난에 대비하려면 아래 권장 백업 방법대로 별도 저장소에도 정기적으로 복사해 두세요.

권장 백업 방법

  1. 모든 사용자가 중요한 입력을 끝낸 시간을 정합니다.
  2. 관리자 계정으로 설정 → 회사·DB를 엽니다.
  3. 백업 파일을 만들고 날짜를 포함한 이름으로 보관합니다.
  4. USB, NAS 등 프로그램 PC와 다른 위치에 한 벌 더 복사합니다.
  5. 정기적으로 백업 파일이 실제로 존재하고 크기가 0이 아닌지 확인합니다.
복원과 전체 초기화는 기존 데이터를 바꿀 수 있습니다. 완전 초기화는 거래처·품목·입출고·매입매출·전표·일정·프로젝트·메모·공지·출퇴근·히스토리를 삭제하지만, 회원 계정과 회사·사업자·출력·사용자 설정 및 로고·도장·워터마크 파일은 유지합니다. 실행 전 서버 내부에 자동 백업 폴더가 만들어지지만 사용자가 내려받은 외부 백업은 아니므로, 반드시 별도 수동 백업도 보관하세요.

문제 해결

11. 자주 생기는 문제

ONE_CLICK_START.bat를 눌러도 실행되지 않습니다.
압축을 완전히 풀었는지 확인하고, 시작 창의 마지막 오류 문장을 확인합니다. 첫 실행이라면 인터넷 연결과 Windows 구성요소 설치 허용 여부를 확인합니다. 보안 프로그램이 차단했다면 신뢰할 수 있는 배포 파일인지 확인한 뒤 허용합니다.
다른 PC나 휴대폰에서 접속되지 않습니다.
서버 PC에서 프로그램이 실행 중인지, 두 기기가 같은 네트워크인지, 주소와 포트가 정확한지 확인합니다. 그다음 Windows 방화벽에서 5000 또는 5443 연결이 허용됐는지 확인합니다.
휴대폰에서 보안 경고가 뜨는데 계속 진행해도 되나요?
네, 정상입니다. 같은 사내 서버에 접속할 때 자체 서명 인증서를 쓰기 때문에 뜨는 경고입니다. "고급" → "(안전하지 않음)으로 이동"을 누르면 되고, 같은 기기에서는 한 번만 하면 됩니다. 자세한 화면은 "2. 모바일에서 접속하기"를 참고하세요.
재고 수량이 예상과 다릅니다.
입출 현황에서 해당 품목과 기간을 조회해 중복 입력, 잘못된 입고·출고 구분과 수량을 확인합니다. 입출고 관리 화면에서 해당 줄을 찾아 수정 버튼으로 바로 고치거나, 삭제 후 다시 입력하세요.
휴대폰 카메라가 열리지 않습니다.
HTTPS 주소로 접속했는지 확인하고 브라우저 사이트 설정에서 카메라 권한을 허용합니다. 다른 앱이 카메라를 사용 중이면 종료한 뒤 다시 시도합니다.
견적서나 전표 인쇄 모양이 이상합니다.
설정의 출력 디자인을 확인하고 브라우저 인쇄 배율을 기본값 또는 100%로 맞춥니다. 고객에게 보내기 전 PDF 미리보기에서 로고, 도장, 페이지 나눔과 금액을 확인합니다.
복원 또는 초기화 전에 무엇을 해야 하나요?
현재 DB를 먼저 별도 위치에 백업하고, 다른 사용자의 접속과 입력을 중단한 다음 관리자만 작업합니다. 작업 직후 로그인, 거래처, 품목, 재고와 최근 전표를 표본 확인합니다.
이 설명서를 다시 보고 싶은데 어디서 여나요?
프로그램 화면 어디서든 키보드의 F7을 누르면 새 탭으로 열립니다. F7을 다른 기능으로 바꿨다면 설정 → 단축키에서 "사용설명서 열기"가 지정된 키를 확인하세요.
문의할 때 함께 알려 주세요. 사용한 메뉴, 발생 시각, 화면에 표시된 정확한 오류 문장, 직전에 한 작업과 문제 화면 캡처가 있으면 원인을 훨씬 빨리 찾을 수 있습니다.
재고 관리 PRO 사용설명서 · 프로그램 안에서 F7 키로 열 수 있습니다.
