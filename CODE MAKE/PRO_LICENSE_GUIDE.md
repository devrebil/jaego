# Pro 라이선스 발급 안내

## 최초 한 번만 준비

`CODE MAKE` 폴더는 이미 초기 설정돼 있습니다. 새 작업 폴더에서 처음 구성할 때만 아래 명령을 실행합니다.

```powershell
python PRO_CODE_TOOL.py --setup
```

생성되는 `pro_license_private_key.pem`은 판매자 전용 비밀키입니다. 고객에게 보내거나 `FREE`, `PRO`, 고객용 ZIP에 넣으면 안 됩니다. 이 파일을 암호화된 저장소와 별도 USB 등에 백업하세요.

## 고객 코드 발급

1. `MAKE_PRO_CODE.bat`을 더블클릭합니다.
2. 고객코드를 입력합니다. 고객코드는 영문 또는 숫자로 시작하고 영문, 숫자, 밑줄, 하이픈만 1~64자로 사용합니다.
3. 화면에 표시된 `PRO CODE` 전체를 고객에게 메일로 보냅니다.
4. 고객은 FREE 프로그램의 `설정 > Pro 전환`에 코드 전체를 붙여넣습니다.

발급한 코드는 `CODE MAKE\issued_licenses` 폴더에 `고객코드.txt` 파일로 저장됩니다. 메일을 다시 보내야 할 때 이 파일을 고객에게 전달하면 됩니다. 같은 고객코드 파일이 이미 있으면 덮어쓰지 않고 발급을 중단합니다.

기본 코드는 만료 없는 영구 라이선스입니다. 같은 고객은 재설치 후에도 받은 코드를 다시 입력할 수 있습니다.

기간제 코드가 필요할 때만 아래처럼 만료일을 지정합니다.

```powershell
python PRO_CODE_TOOL.py --customer-code "CUST-001" --expires 2027-12-31
```

## 꼭 지킬 사항

- 고객별로 발급한 코드와 라이선스 번호를 주문 기록에 함께 보관합니다.
- `pro_license_private_key.pem`을 새로 만들거나 바꾸지 않습니다.
- 비밀키를 잃으면 기존 배포본과 맞는 새 코드를 더 이상 발급할 수 있으므로 백업본을 복구해야 합니다.
- Python 소스 배포 방식은 전문적인 코드 변조까지 완전히 막지는 못합니다. 이 구조는 일반적인 무단 활성화와 임의 코드 생성을 막는 용도입니다.
